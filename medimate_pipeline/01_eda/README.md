# 01 - Exploratory Data Analysis

This was the first look at the kidney waitlist dataset.

I used this notebook to understand the size of the data, outcome distribution, repeated patient registrations, missing values, follow-up time, and the main patient characteristics.

Some of the areas I looked at were age, dialysis status, blood type, functional status, region, and listing year.

One important issue was that recent listing years contain much more censoring because those patients have had less time to reach an outcome.

This step was mainly used to understand the dataset before making cleaning or modeling decisions.
