# MediMate Kidney Waitlist Analysis

This folder contains my analysis pipeline for the MediMate kidney waitlist project.

The goal of the project is to study kidney waitlist outcomes and identify patients who may be at higher risk of dying or becoming too sick for transplant while waiting.

I kept the work in the same order that I completed it:

1. Exploratory data analysis
2. Data cleaning
3. Model preparation
4. Classification modeling
5. Survival modeling
6. Final analysis

Each folder contains the notebook for that step and an `outputs` folder for the results created by that notebook.

Raw OPTN data, patient-level predictions, preprocessing matrices, and trained model files are not included in this repository because they are not appropriate for public sharing.

The models in this project are for research and analysis. They are not intended to make clinical decisions or organ allocation decisions.
