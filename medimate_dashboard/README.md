# MediMate Kidney Waitlist Risk Explorer

This website presents the full analysis pipeline for the MediMate kidney waitlist project.

It is designed for both technical and nontechnical readers. Each section starts with a plain-English explanation, while detailed tables, modeling decisions, subgroup results, feature importance, and downloadable analysis files are available for readers who want more technical detail.

The website covers:

1. Exploratory data analysis
2. Data cleaning
3. Model preparation
4. Classification modeling
5. Survival and competing-risk modeling
6. Final combined analysis
7. Fairness and explainability
8. Reproducibility and project files

Only aggregated public results are used by the website.

Raw OPTN data, patient-level predictions, preprocessing matrices, and trained model files are intentionally excluded.

This project is for research and educational use. It is not a clinical or organ-allocation decision tool.
